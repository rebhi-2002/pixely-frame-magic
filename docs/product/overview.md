# Product Overview

Academia منصة تعليمية متعددة الأدوار تستهدف الطالب والمعلم وولي الأمر والمشرف والإدارة. النسخة الحالية من الفرونت تحتوي shell عام، مصادقة، لوحات أدوار، مكتبة، صفحات تعليمية، إدارة مستخدمين وصفحات وصلاحيات، مع وجود أجزاء تنتظر عقود API إضافية.

## الوعد الأساسي

تقديم تجربة تعلم وإدارة واضحة، عربية/إنجليزية، متجاوبة، وتكشف حالة البيانات بصدق. لا تعرض الواجهة بيانات تجريبية على أنها إنجازات أو نتائج إنتاجية.

## المستخدمون

| الشخصية   | الاحتياج الرئيسي                                     |
| --------- | ---------------------------------------------------- |
| الطالب    | الوصول للمكتبة، التعلم، المحاولات، الأخطاء، والإنجاز |
| المعلم    | إدارة المحتوى والكورسات والتقييم                     |
| ولي الأمر | رؤية تقدم الأبناء والتقارير                          |
| المشرف    | متابعة الطلاب والمعلمين والتقارير                    |
| الإدارة   | المستخدمون والصفحات والصلاحيات والإعدادات            |

## حدود النسخة الحالية

المصادقة (لكل الأدوار)، إدارة المستخدمين، الملف الشخصي وكلمة المرور، إدارة الصفحات/الثوابت والصلاحيات، **والمحفظة المالية بالكامل (شحن/سحب/سجل حركات)** لها عقد API حقيقي ومربوط. أما الكورسات والدروس والاختبارات والتسجيلات والشهادات والإشعارات والتقارير فتحتاج endpoints مكتملة قبل تحويلها إلى server state — بوابة ولي الأمر تحديدًا مربوطة بالكود لكن معطّلة عمليًا (لا endpoint لربط الأبناء). راجع [`docs/api/frontend-integration-status.md`](../api/frontend-integration-status.md) للتفاصيل الكاملة.
