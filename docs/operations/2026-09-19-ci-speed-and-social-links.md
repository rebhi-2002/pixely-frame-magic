# تقرير: تسريع أوامر الفحص + تجهيز روابط السوشال ميديا — 2026-09-19

## 1) تسريع `npm run validate` (اقتراح كان موجود بملف Error.txt)

كان `validate` يشغّل 4 فحوصات **بالتسلسل** (`&&`)، وبدون أي cache — كل
فحص (eslint/prettier/tsc) يعيد فحص كل ملفات المشروع من الصفر كل مرة.

**التطبيق**:

1. `run-p` (من `npm-run-all2` — بديل مدعوم لـ`npm-run-all` الأصلية
   المتوقفة عن الصيانة) بدل `&&` — الفحوصات الأربعة تشتغل بالتوازي.
2. `--cache` لـ`eslint` و`prettier` (`lint`, `lint:fix`, `format:check`) —
   بيفحصوا الملفات المتغيّرة بس بالمرات التالية.
3. `incremental: true` + `tsBuildInfoFile` بـ`tsconfig.json` — نفس المبدأ لـ`tsc`.
4. CI (`.github/workflows/ci.yml`): خطوة `actions/cache@v4` جديدة تحافظ
   على مجلد الكاش بين تشغيلات الـCI المتتالية (بدونها، كل تشغيل CI على
   runner جديد بالكامل، فالكاش المحلي ما كان رح يفيد إشي هناك).

**النتيجة المقاسة محلياً**: أول تشغيل (بدون كاش) ~57 ثانية → تشغيل تاني
(بالكاش) **~8 ثواني**.

⚠️ ملاحظة تقنية بسيطة واجهتها: مسار الكاش الأول يلي جرّبته
(`node_modules/.cache/prettier/` بشرطة مائلة بالآخر) سبّب تعارض
`ENOTDIR` (prettier حاول يعامله كمجلد بس كان ملف من محاولة سابقة) —
بدّلته لمسار ملف مباشر بدون شرطة مائلة (`prettier-cache`), نفس الشي
لـeslint، وحليت المشكلة.

## 2) تجهيز مكان روابط السوشال ميديا + واتساب (بدون حسابات حقيقية بعد)

ملف جديد `src/lib/social-links.ts` — مصدر واحد لكل الروابط:

- `SOCIAL_LINKS`: Instagram, Facebook, YouTube — كل وحدة `url: null` حالياً.
- `SUPPORT_WHATSAPP_NUMBER`: `null` حالياً.

**مبدأ التصميم** (نفس مبدأ "قريباً" المستخدم بقسم الآراء وكتالوج
الكورسات): الأيقونة **ما بتظهر بالفوتر إطلاقًا** طالما `url` هو `null` —
بدل ما تظهر كرابط ميت. أول ما ينشئ حساب حقيقي، يبدّل `null` بالرابط
الفعلي بسطر واحد بـ`social-links.ts`، وتظهر الأيقونة تلقائيًا بدون أي
تعديل كود إضافي بمكوّن الفوتر نفسه.

**ليش هاي المنصات بالذات (رأيي)**:

- **Instagram + Facebook + YouTube**: الأقوى لجمهور طلاب التوجيهي
  وأولياء أمورهم بالسوق الفلسطيني، ويوتيوب يناسب موديل الكورسات
  المسجّلة/المعاينات.
- **LinkedIn**: **ما أضفته** — شبكة مهنية (توظيف/B2B)، مش وين الجمهور
  المستهدف (طلاب + أهاليهم) موجود فعليًا. ممكن يفيد لاحقًا لتجنيد معلمين،
  مش أولوية إطلاق.
- **TikTok**: قوي جداً لنفس الفئة العمرية بس ما في أيقونة جاهزة بمكتبة
  الأيقونات الحالية (`lucide-react`) — يحتاج رسم أيقونة مخصّصة لو تقرر
  تضيفه، سهل التنفيذ لاحقًا (السكيما بـ`social-links.ts` بتتحمّل أي منصة
  إضافية بسهولة).

**الملفات المعدَّلة**: `src/lib/social-links.ts` (جديد),
`src/components/site/public-layout.tsx` (قسم الأيقونات بالفوتر).
