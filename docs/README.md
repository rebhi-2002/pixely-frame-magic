# Frontend Documentation

هذا المجلد هو فهرس التوثيق الرسمي لفرونت Academia.

| القسم | المحتوى |
|---|---|
| `product` | هدف المنتج والجمهور ونطاق النسخة الحالية |
| `architecture` | طبقات الفرونت، routes، state، وحدود API وحماية المسارات |
| `design` | Design System وUX وكتالوج المكونات |
| `api` | عقود التكامل وملفات Postman |
| `integrations` | متغيرات البيئة والأنظمة الخارجية |
| `standards` | قواعد الكود والمساهمة |
| `qa` | الاختبارات، الوصول، الأداء، وقائمة الفحص |
| `operations` | النشر والإصدارات والتراجع |
| `decisions` | القرارات المعمارية الموثقة |

ابدأ من [README](../README.md)، ثم راجع [خريطة المسارات](architecture/routes.md) و[حدود API](architecture/api-boundary.md) قبل تعديل شاشة مرتبطة بالباك إند.
