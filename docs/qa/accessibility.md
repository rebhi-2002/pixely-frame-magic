# Accessibility

استهدف WCAG 2.1 AA قدر الإمكان. كل input له label، وكل icon-only button له `aria-label`، وكل dialog له title، ويجب أن يعمل التنقل بالكيبورد مع focus ring واضح. لا تعتمد على اللون وحده، واحترم reduced motion.

اختبر 375px و768px و1280px، مع العربية والإنجليزية. راجع Sheet/Dialog/table/pagination والرسائل عند الفشل.
