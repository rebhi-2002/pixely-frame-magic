# Performance Budget

راقب LCP وCLS وINP، زمن ظهور المحتوى الرئيسي، حجم JavaScript، وعدد الطلبات الحرجة. استخدم أبعادًا ثابتة للصور، لا تحمل ميزات داخلية في الصفحة العامة، وتجنب layout jump عند loading.

بعد استقرار بيئة النشر، تحفظ baseline من Lighthouse ويحدد الفريق ميزانية initial JS والصور والطلبات. لا تفشل CI برقم غير مقاس أو غير متفق عليه.
