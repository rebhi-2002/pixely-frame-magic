# Design System

يعتمد النظام البصري على tokens في `src/styles.css` ومكونات UI مشتركة. كل تغيير بصري يجب أن يحافظ على semantic colors، focus ring، radius، spacing، dark mode، وRTL/LTR.

| الفئة      | القاعدة                                                              |
| ---------- | -------------------------------------------------------------------- |
| Typography | عناوين واضحة، نص body قابل للقراءة، وعدم استخدام وزن/لون وحده للمعنى |
| Color      | اللون الدلالي لا يستخدم وحده لتمييز الخطأ أو النجاح                  |
| Spacing    | استخدم scale موحدًا وتجنب قيمًا عشوائية متكررة                       |
| Radius     | حافظ على hierarchy واضح بين control/card/dialog                      |
| Focus      | focus-visible واضح للكيبورد في كل interactive control                |
| Motion     | تحريك خفيف، مع احترام `prefers-reduced-motion`                       |
| Direction  | استخدم logical properties واختبر RTL وLTR                            |

أي primitive جديد يوثق في `component-catalog.md` مع default/disabled/loading/invalid states.

## نظام حركة الدخول (Entrance motion)

`<Reveal>` (`src/components/ui/reveal.tsx`) هو المكوّن الوحيد لحركة "ظهور
عند السكرول" بكل المشروع — **3 أنماط مسمّاة بس (`variant`)، مش أرقام حرة
بكل ملف**. القاعدة: أضف variant جديد هون فقط لو نوع محتوى فعليًا مختلف
محتاجه، مش رقم `y`/`duration` حر بملف صفحة.

| Variant   | الاستخدام                                                                                            | y (px) | duration (s) |
| --------- | ---------------------------------------------------------------------------------------------------- | ------ | ------------ |
| `content` | الافتراضي — بطاقات/أقسام مستقلة (مزايا، تدوينات، خطوات)                                              | 24     | 0.7          |
| `stat`    | بطاقات أرقام/إحصائيات (مع `AnimatedCounter`) — انزلاق أخف عمدًا حتى ما يتنافس مع حركة عدّ الرقم نفسه | 12     | 0.5          |
| `compact` | شبكات صغيرة/كثيفة العناصر (تايلز لوحة تحكم مضغوطة) — محجوز لحالة مستقبلية، لسا ما استُخدم            | 16     | 0.55         |

```tsx
<Reveal variant="stat" delay={i * 0.05}>
  <StatCard ... />
</Reveal>
```

`delay` يبقى دايمًا حر (تتابع stagger حسب index العنصر)، بس `y`/`duration`
يُشتقّان من الـvariant افتراضيًا. تجاوز يدوي لهم متاح تقنيًا بس تجنّبه —
لو حسّيت إنك محتاج رقم مختلف، هاد إشارة إنه محتاج variant رابع موثّق هون،
مش استثناء صامت بملف الصفحة.

**قاعدة ملازمة لأي variant جديد:** لا تضيف `interactive-card` (رفعة hover)
لعنصر مش قابل للنقر (بطاقة عرض بيانات ثابتة) — حركة "استجابة للتحويم"
توحي بتفاعل غير موجود فعليًا. راجع التعليقات بجانب بطاقات الإحصائيات
بـ`kit.tsx`/`index.tsx` كمثال مطبّق.
