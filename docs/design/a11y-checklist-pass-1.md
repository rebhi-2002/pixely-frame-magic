# تقرير: فحص إمكانية الوصول (Accessibility) — دفعة 1

> مصدر القواعد: `ui-ux-pro-max-skill` (github.com/nextlevelbuilder/ui-ux-pro-max-skill)،
> قسم `references/quick-reference.md` → فئة "Accessibility (CRITICAL)"،
> تحديدًا قاعدة `icon-context` / `aria-labels`. راجع نقاش القرار الكامل
> بخصوص باقي أقسام الأداة (الألوان/الخطوط/الأنماط) — لم تُعتمد لأنها
> ولّدت 3 نتائج متضاربة لنفس المنتج (teal+Noto Naskh، بنفسجي+Garamond،
> OLED أسود+نيون) عبر 3 محاولات بصيغ مختلفة لنفس الوصف. الجزء المعتمد
> هنا هو القواعد الحتمية (deterministic rules) فقط، غير المولّدة.

## القاعدة المطبَّقة

> أيقونة بمفردها داخل زر (بدون نص مرئي) لازم يكون إلها اسم يوصل
> لقارئ الشاشة (`aria-label`). وجود `title=""` بس مش كافي — مش كل
> قارئ شاشة بيعلن عنه بشكل موثوق.

## النتيجة

- **69 زر** تم فحصه وتصحيحه عبر **30 ملف** (كان صفر منهم فيه
  `aria-label`، أغلبها معتمدة بس على أيقونة وحدها أو `title` بصري).
- التوزيع: 5 ملفات صُححت يدويًا (فحص دقيق لكل حالة)، 42 + 27 = 69
  إصلاح عبر سكربت مطابقة نصية آلي (مو regex كامل — تفادينا مشكلة
  إن `=>` بالـJSX فيها `>` حرفي بيكسر أي regex ساذج على وسم `<Button>`).
- **3 حالات اتحطت يدويًا بعد مراجعة** بدل تخمين تلقائي:
  - `roles-manager.tsx`: زر "الصلاحيات" كان عنده `title` بس، ضفنا
    `aria-label` بنفس النص.
  - `flashcards.tsx`: زرّي التنقل بين البطاقات (`ChevronRight`/
    `ChevronLeft`) — الأسماء محسوبة حسب اتجاه RTL الفعلي بالكود
    (`goToCard(-1)` هو "البطاقة السابقة" وبيتحرك بصريًا يمين، مو مجرد
    تخمين من اسم الأيقونة).

## التحقق (مو مجرد "خلص الكود")

بعد التعديلات الآلية على 30 ملف، اتشغّل فعليًا (مو افتراض):

```
npm run typecheck   → 0 أخطاء
npm run lint         → 24 خطأ Prettier (تنسيق فقط) → npm run format → 0
npm run build         → نجح، بنية Vercel كاملة اتبنت بدون أخطاء
```

يعني الإصلاحات مو بس "منطقيًا صح" — المشروع فعليًا بيبني ويمر التحقق
الكامل بعدها.

## اللي ما تعدّل (وليش)

- نظام الألوان/الخطوط/`Reveal` — ما لهم علاقة بهالدفعة، وبالأساس
  مقرر سابقًا نحافظ عليهم.
- باقي قواعد `quick-reference.md` (contrast ratios الفعلية، keyboard
  nav، reduced-motion، touch-target 24×24px) — لسا ما تفحصت بهالدفعة.
  دي **الدفعة الجاية** لو بدك نكمل بنفس المنهجية.
