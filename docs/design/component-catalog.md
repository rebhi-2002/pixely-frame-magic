# Component Catalog

| المجال | المكونات الحالية | الحالات التي يجب توثيقها |
|---|---|---|
| Controls | Button, Input, Select, Checkbox, Switch | default, hover, focus, invalid, disabled, loading |
| Overlays | Dialog, Sheet, AlertDialog | open, close, escape, mobile, RTL/LTR |
| Data | DataTable, LoadingState, EmptyState, ErrorState | loading, empty, error, retry, populated |
| Layout | PublicLayout, AuthShell, AppSidebar, PageHeader | desktop, tablet, mobile, collapsed |
| Feedback | toast/banner/inline error | success, validation, server error, dismiss |

الـcomponent العام لا يعرف API أو role business logic. أضف props اختيارية بدل كسر الاستخدامات القائمة، وراجع accessibility قبل الدمج.
