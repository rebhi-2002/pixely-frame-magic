## 1. الرئيسية `/` — ✅ تم (تعديل حقيقي، مو mechanical pass)

> ⚠️ أول محاولة على هالصفحة كانت سطحية (استبدال قيمة CSS variable بس)
> وتراجعنا عنها بعد نقاش — التفاصيل تحت هي النسخة الفعلية المُنفَّذة.

**القرار النهائي على هيرو الصفحة الرئيسية (بعد مراجعة كاملة):**

| العنصر | القرار | السبب |
|---|---|---|
| خلفية شبكة SVG (`visual-canvas`) | حذف كامل | طبقة زخرفية فوق طبقة، بلا وظيفة |
| 3 دوائر gradient متنافسة (`surface-mesh`) | حذف كامل | استبدلت بتوهّج واحد (`soft-glow`) خلف الصورة فقط |
| `HeroMockup` (لوحة تحكم وهمية: glass + بطاقات عائمة + 3D tilt) | حذف الاستخدام من هالصفحة | glassmorphism + floating cards فعليين بالكود، أنماط SaaS عامة مؤكدة مو مجرد استنتاج |
| صف 3 كروت إحصائية تحت الهيرو (4 مستويات/100%/3 مساحات) | حذف كامل، بدون بديل | كانت مكررة حرفيًا لبطاقة المواد، والأرقام نفسها مش مقنعة كدليل ثقة. الفراغ بعد الأزرار مقصود. |
| صورة حقيقية لطالب يذاكر | **أُضيفت** (`public/images/home/hero-student.jpg`) | أول استخدام فعلي لـphotography بالموقع كامل. مصدرها مرجع قدّمه المستخدم مباشرة — **placeholder مؤقت، بينتظر تصوير/ترخيص نهائي**. تم قصّ الجزء العلوي-الشمال من الصورة الأصلية (شعار ونص بالأزرق ما بيطابق هوية أكاديميا) قبل الاستخدام. |
| بطاقة تقدّم فوق الصورة | أُعيد بناؤها بالكامل بكود حقيقي (مو جزء من الصورة) | خلفية معتمة (`bg-card`) مش زجاجية، ألوان `primary/info/success` الفعلية مو أزرق عام، أسماء مواد توجيهي حقيقية (اللغة العربية/الفيزياء/الرياضيات) بدل أيقونات صامتة |

**الملفات المتأثرة:**
- `src/routes/index.tsx` — إعادة بناء قسم الهيرو بالكامل + حذف `stats`
  array واستبدالها بـ`heroSubjects`، حذف استيراد `HeroMockup` و
  `AnimatedCounter` (صاروا غير مستخدمين).
- `public/images/home/hero-student.jpg` — أصل جديد (الصورة المُجهّزة).

**ليش باقي الصفحة (bento grid قسم المزايا) ما تغيّر:**
لسا أفضل جزء موجود — بطاقة "المكتبة" غير متماثلة الحجم (`lg:col-span-2
lg:row-span-2`) مع illustration مخصصة. هاد النمط (composition غير
متماثل) هو المرجع لصفحات تانية، مو شي يحتاج إصلاح.

**فجوة معروفة، بانتظار تأكيدك:** ما فيني أتحقق بصريًا من النتيجة
(بدون متصفح/معاينة حية بهالبيئة) — لازم screenshot حقيقي بعد ما
تشغّل المشروع قبل ما ننتقل لصفحة `/courses`.

## 2-3. الكورسات `/courses` + دليل المعلمين `/teachers` — ✅ لا تغيير لازم

مفاجأة إيجابية بالفحص: هاتين الصفحتين **مو من ضمن مجموعة الـ9 صفحات**
اللي كانت تستخدم `surface-mesh` — هني أصلًا يستخدموا utility مختلفة
(`surface-grid`، تعريف منفصل بـ`styles.css`) + عندهم عناصر تمييز
موجودة فعلًا بالكود:
- `PhotoAvatar` مكوّن مخصص لصور المعلمين (مو icon عام) — موجود
  ومُستخدم بـ`courses.tsx`.
- شريط لوني علوي حسب المادة على كروت الكورسات — تعليق بالكود صراحة
  يقول "يكسر تكرار البطاقات البيضاء المتطابقة".

يعني المطوّر أصلًا انتبه لمشكلة التكرار بهاي الصفحتين تحديدًا وعمل
لها معالجة، بس ما انتشرت لباقي الصفحات. **لا تغيير هون بهالجولة** —
فقط لاحظنا إنه نمط `PhotoAvatar` + الشريط اللوني هو بالضبط نوع
الحل المطلوب تعميمه على صفحات تانية بدل إعادة اختراعه.

⚠️ ملاحظة مستقلة (مسجّلة بـ`audit-known-issues.md` #3): كلا
الصفحتين رجعوا error state وقت التقاط الصور — نحتاج نتأكد الصفحة
شغالة ببيانات حقيقية قبل أي حكم نهائي على التركيب الكامل محمّل.

## 4-7. كيف تعمل / الأسعار / للمعلمين / لأولياء الأمور — ✅ تم

**التعديل:** الهيرو بكل الأربع صفحات كان يستخدم `surface-mesh` (نفس
نسخة الرئيسية بالحرف) → استُبدل بـ`surface-mesh-quiet` (دائرة لونية
وحدة خافتة بدل ثلاث). التغيير سطر واحد لكل ملف:

```
src/routes/how-it-works.tsx
src/routes/pricing.tsx
src/routes/for-teachers.tsx
src/routes/for-parents.tsx
```

**ليش بس الهيرو ومش الكروت تحته:** هاد أول تمريرة (mechanical pass) —
الهدف إنه ولا صفحة داخلية تحس "هاي نفس الرئيسية". تفكيك نمط الكروت
المتطابقة جوا كل صفحة (قسم 3.7 و3.1 بالـaudit) قرار composition أعمق
لكل صفحة لحالها — هاد التالي، مو ضمن هاي الدفعة الميكانيكية.

**ملاحظة لصفحة "الأسعار" تحديدًا:** جدول المقارنة موجود فيها أصلًا
composition جيد وغير متكرر (راجع قسم 2 بالـaudit) — ما يحتاج لمسة.
