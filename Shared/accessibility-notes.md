# ملاحظات Accessibility — أكاديميا (للتنفيذ لاحقاً من طرفك)

> ملف ملاحظات فقط، بدون تنفيذ. مبني على قراءة الكود الحالي (styles.css، kit.tsx، route.tsx، app-sidebar.tsx).

## 1) المعيار المستهدف
- WCAG 2.2 مستوى AA كحد أدنى، مع دعم RTL كامل (عربي أولاً) وإنجليزي.

## 2) خيارات للمستخدم (لوحة "إمكانية الوصول" — تُحفظ بـlocalStorage وتُطبَّق كـclass/CSS var على <html>)
| الخيار | التنفيذ المقترح |
|---|---|
| حجم الخط (100% / 115% / 130% / 150%) | متغير `--font-scale` ويُضرب به الـroot font-size؛ تأكد أن كل الأحجام بـrem |
| تباين عالٍ | class `contrast-high` يعيد تعريف tokens (foreground/background/border/primary) بنسب ≥ 7:1 |
| تقليل الحركة | class يوقف animate-float/reveal/route-fade؛ يحترم أصلاً `prefers-reduced-motion` (موجود بـstyles.css) — أضف مفتاحاً يدوياً فوقه |
| خط مقروء (يقلل الزخرفة) | تبديل `--font-display-family` إلى نفس خط النص Cairo |
| تباعد أسطر/حروف أوسع | `--line-height-scale` و`letter-spacing` |
| تمييز الروابط (تسطير دائم) | class `underline-links` |
| حجم مؤشر/تركيز أكبر | تكبير outline الـfocus-visible إلى 3px مع offset |
| وضع الألوان | موجود (ليلي/نهاري)؛ أضف "حسب النظام" إن لم يكن |
| اختيار اللغة | موجود؛ تأكد من تحديث `lang` و`dir` على <html> |

## 3) قائمة تدقيق بالكود الحالي
1. **التباين**: القائمة الجانبية غامقة ثابتة بالوضعين — تحقق من نسبة `--sidebar-foreground` مع `--sidebar` والحالات hover/active/muted. اسم "Academia" صُلّح ليستخدم `text-sidebar-foreground`.
2. **التنقل بلوحة المفاتيح**: افتح كل الصفحات بـTab فقط؛ تأكد من ترتيب منطقي، وعدم وجود فخ تركيز داخل القائمة الجانبية على الموبايل والـDialogs.
3. **Skip link**: أضف "تخطّي إلى المحتوى" أول <body> يشير إلى `<main id="main">` (route.tsx و public-layout).
4. **Landmarks**: `<nav aria-label>` للقائمة الجانبية، `<main>`، `<header>`، `<footer>`؛ عناوين h1 واحدة بكل صفحة (AppPage/PageHeader).
5. **الأيقونات**: أزرار الأيقونة فقط (Menu، حذف، تعديل، إغلاق، Pagination) لازم `aria-label` ثنائي اللغة عبر `bi()`؛ الأيقونات الزخرفية `aria-hidden`.
6. **الجداول**: `<th scope="col">`، و`<caption>` أو aria-label، وحالات الفراغ/التحميل بـ`role="status"` و`aria-live="polite"`.
7. **النماذج**: كل input له `<label htmlFor>`، رسائل الخطأ مربوطة بـ`aria-describedby` مع `aria-invalid`، وملخص أخطاء يستلم التركيز عند فشل الإرسال.
8. **الـToasts (sonner)**: تأكد أنها `aria-live` وتبقى وقتاً كافياً؛ لا تعتمد على اللون وحده للحالة (Badge نجاح/خطأ عندها نص/أيقونة).
9. **الألوان**: لا تنقل المعنى باللون فقط (حالات الكورس: مسودة/منشور/مؤرشف — عندها نص، جيد).
10. **الحركة**: الـBackdrop-blur والـsticky header — تأكد من قراءة المحتوى عند تقليل الشفافية (خيار `prefers-reduced-transparency`).
11. **الموبايل**: أهداف اللمس ≥ 44×44px (أزرار Pagination والأيقونات)، وقفل السكرول خلف القائمة (مُنفَّذ) مع إعادة التركيز لزر الفتح عند الإغلاق، وإغلاق بـEsc.
12. **RTL**: الأسهم والأيقونات الاتجاهية تنعكس (Pagination السابق/التالي)، والأرقام/التواريخ بتنسيق حسب اللغة.
13. **الصور والرسومات SVG**: `role="img"` مع `aria-label` أو `aria-hidden` إن كانت زخرفية (illustrations.tsx و hero-mockup — الأخير aria-hidden حالياً).
14. **عنوان الصفحة**: يتغير عند كل تنقل (موجود عبر head())، وإعلان التنقل للقارئ (route announcer).
15. **الوقت**: لا يوجد مؤقتات تنتهي بلا تحذير؛ الجلسة المنتهية تُبلَّغ بوضوح.

## 4) الاختبار
- أدوات: axe DevTools، Lighthouse (Accessibility)، WAVE، تحقق يدوي بـNVDA/VoiceOver/TalkBack بالعربية.
- سيناريوهات: تسجيل الدخول، تصفح دليل المعلمين، ملف المعلم، الشحن بالمحفظة (رفع إيصال)، لوحة الأدمن (جداول + Dialogs).
- اختبار آلي بالـCI: `@axe-core/playwright` على الصفحات العامة ولوحة كل دور.

## 5) ترتيب العمل المقترح
1. Skip link + landmarks + aria-labels (أسرع مكسب).
2. النماذج والأخطاء والـDialogs (تركيز وقارئ الشاشة).
3. لوحة الخيارات (حجم الخط/التباين/الحركة).
4. تدقيق التباين لكل tokens بالوضعين + الوضع العالي.
5. اختبارات آلية + مراجعة يدوية.
