# قائمة العمل المطلوبة لإكمال المشروع

## أولًا: عينات JSON المطلوبة من Postman

### NE-01 — حجوزات المعلم وإعادة الجدولة

#### 1. حجوزات المعلم

```http
GET {{baseUrl}}/api/Booking/TeacherBookings?status={{status}}
```

المطلوب:

- عينة حجز واحدة على الأقل لكل حالة موجودة.
- استخدام قيم الحالات الرقمية `1..6`.
- إرسال أسماء الحالات المقابلة للأرقام.

#### 2. طلبات إعادة الجدولة للمعلم

```http
GET {{baseUrl}}/api/Booking/TeacherRescheduleRequests?status={{status}}
```

المطلوب:

- عينة لكل حالة متوفرة.
- توضيح أسماء الحالات الرقمية `1..4`.

---

### NE-02 — تفاصيل حجز الطالب

```http
GET {{baseUrl}}/api/Student/GetBooking?id={{bookingId}}
```

المطلوب:

- عينة لحجز مؤكد `Confirmed`.
- عينة لحجز مكتمل `Completed`.
- توضيح وجود أو عدم وجود:
  - `isRated`
  - `rating`
  - تفاصيل الدفع
  - سياسة الإلغاء
  - موعد/مهلة الإلغاء
  - أهلية إعادة الجدولة

---

### NE-03 — حالة دفع الحجز

```http
GET {{baseUrl}}/api/Student/BookingPayment?bookingId={{bookingId}}
```

المطلوب:

- عينة لحجز مؤكد ورصيده كافٍ.
- عينة لحالة رصيد غير كافٍ.
- توضيح وقت الخصم الفعلي للمبلغ.

---

### NE-04 — طلبات إعادة جدولة الطالب

```http
GET {{baseUrl}}/api/Student/MyRescheduleRequests
```

المطلوب:

- عينة طلب معلّق.
- عينة طلب مرفوض.
- عينة طلب موافَق عليه.
- أسماء الحالات الرقمية/النصية.

---

### NE-05 — تفاصيل الدرس للطالب

```http
GET {{baseUrl}}/api/Student/GetLesson?id={{lessonId}}
```

المطلوب:

- عينة درس حضوري تحتوي على القاعة/الموقع.
- عينة درس أونلاين تحتوي على:
  - منصة الاجتماع.
  - رابط الاجتماع.
  - `canJoin`.
  - تعليمات الاجتماع إن وجدت.

---

### NE-06 — تفاصيل الكورس المسجّل

```http
GET {{baseUrl}}/api/Student/GetCourse?id={{courseId}}
```

المطلوب:

- عينة كورس يحتوي على مجموعة ودروس.
- عينة كورس لا يحتوي على دروس.
- توضيح شكل المجموعة والـ`groupId` والدروس.

---

### NE-07 — سجل حضور الطالب

```http
GET {{baseUrl}}/api/Student/Attendance?from={{from}}&to={{to}}&courseId={{courseId}}
```

المطلوب:

- سجلات بالحالات الأربع:
  - Present
  - Absent
  - Late
  - Excused
- توضيح هل الرد يحتوي على نسبة حضور جاهزة أم يجب حسابها في الفرونت.

---

### NE-08 — نتائج امتحانات الطالب

```http
GET {{baseUrl}}/api/Student/ExamResults?courseId={{courseId}}
```

المطلوب:

- أكثر من نتيجة امتحان.
- الحقول المطلوبة:
  - عنوان الامتحان.
  - التاريخ.
  - الدرجة.
  - المجموع.
  - النسبة إن وجدت.
  - الملاحظات.

---

### NE-09 — كورس المعلم ومجموعاته

```http
GET {{baseUrl}}/api/Course/GetMineById?id={{courseId}}
```

المطلوب:

- توضيح وجود `groupId`.
- توضيح هل الكورس يحتوي على مجموعة واحدة أو عدة مجموعات.
- شكل بيانات المجموعة.
- شكل الدروس المرتبطة بالمجموعة.
- توضيح علاقة الكورس بالمعلم.

---

### NE-10 — قائمة كورسات المعلم

```http
POST {{baseUrl}}/api/Course/GetAll
```

Body مثال:

```json
{
  "searchValue": "",
  "sortColumn": "",
  "sortColumnDirection": "asc",
  "pageSize": 20,
  "skip": 0
}
```

المطلوب:

- استخدام حساب معلم حقيقي.
- توضيح هل الرد يعيد كورسات المعلم الحالي فقط أم جميع الكورسات.
- توضيح حقول pagination والعدد الكلي.

---

### NE-11 — طلاب المجموعة

```http
GET {{baseUrl}}/api/Course/GetGroupStudents?groupId={{groupId}}&keyword={{keyword}}
```

المطلوب:

- عينة مجموعة تحتوي على طلاب.
- عينة مجموعة بلا طلاب.
- توضيح الحقول المرجعة لكل طالب، خصوصًا:
  - الاسم.
  - الهاتف.
  - الموقع.
  - الطالب ID إن وجد.
- عينة نتيجة بحث باستخدام `keyword`.

---

### NE-12 — جدول دروس الكورس للمعلم

```http
GET {{baseUrl}}/api/Lesson/GetSchedule?courseId={{courseId}}&groupId={{groupId}}
```

المطلوب:

- عينة تحتوي على درس حضوري.
- عينة تحتوي على درس أونلاين.
- توضيح ترتيب الدروس والحقول الخاصة بالقاعة والاجتماع.

---

### NE-13 — مصادر المادة والتصنيف والصف

#### 1. نافذة بيانات المعلم/القوائم

```http
GET {{baseUrl}}/api/Teacher/CreateEditModal?id={{teacherId}}
```

#### 2. الثوابت والقوائم

```http
POST {{baseUrl}}/api/Constant/GetAll
```

Body حسب صيغة DataTable المعتمدة في الباك اند.

المطلوب:

- مصدر `subjectId`.
- مصدر `categoryId`.
- مصدر `gradeId`.
- قيم `parentId` المطلوبة إن وجدت.
- أسماء القوائم وحقول IDs.
- توضيح هل `Teacher/PublicProfile` يعيد IDs أم أسماء فقط.

---

### NE-14 — تحقق اختياري من endpoints الموجودة بالكود

#### Student

```http
GET {{baseUrl}}/api/Student/Dashboard
GET {{baseUrl}}/api/Student/Schedule?From={{from}}&To={{to}}&CourseId={{courseId}}&TeacherId={{teacherId}}&Mode={{mode}}
GET {{baseUrl}}/api/Student/Progress
```

#### Parent

```http
GET {{baseUrl}}/api/Parent/MyChildren
GET {{baseUrl}}/api/Parent/ChildAttendance?studentId={{studentId}}&from={{from}}&to={{to}}
GET {{baseUrl}}/api/Parent/ChildExamResults?studentId={{studentId}}
```

#### Wallet

```http
GET {{baseUrl}}/api/Wallet/MyWallet
POST {{baseUrl}}/api/Wallet/GetTransactionHistory
```

#### Teacher

```http
GET {{baseUrl}}/api/Teacher/PublicProfile?id={{teacherId}}
GET {{baseUrl}}/api/Teacher/Availability?teacherId={{teacherId}}&mode={{mode}}&date={{date}}
```

المطلوب: عينة JSON واحدة لكل endpoint للتأكد من أن الأنواع الموجودة بالكود ما زالت مطابقة.
