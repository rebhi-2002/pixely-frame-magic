# تحديث الربط مع الباك اند — ملخص التغييرات

## ✅ تم تنفيذه فعليًا بهالجولة

1. **`src/lib/bi.ts`** — إصلاح خريطة أسماء الأدوار (`ROLE_BY_NAME`). كانت
   تطابق فقط أسماء بيانات الديمو ("طالب"، "معلم"، "ولي أمر"، "مدير عام")
   وليس الأسماء الحقيقية المزروعة بالباك اند ("الطالب"، "المعلم"، "ولي
   الامر"، "مدير النظام") — أي مستخدم حقيقي غير الأدمن كان ينحط تلقائيًا
   بمساحة الطالب. صارت الخريطة تدعم الاثنين معًا.

2. **`src/integrations/backend/admin-permissions.ts`** — استبدال القائمة
   الثابتة `BACKEND_USER_TYPES` (نوعين فقط) بدالة `listBackendUserTypes()`
   تجيب الأنواع الـ5 الحقيقية ديناميكيًا من `/api/User/CreateEditModal`.
   حُدّث `backend-permissions-manager.tsx` تبعًا لذلك.

3. **`src/integrations/backend/auth.ts`** — دالة `register()` جديدة تتصل
   بـ`/api/Auth/Register` فعليًا (بدل الرسالة الثابتة "قيد الربط").

4. **`src/routes/signup.tsx`** — التسجيل الحقيقي لدوري الطالب وولي الأمر:
   أُضيف حقلا الهاتف والجنس (إجباريان بالباك اند وكانا ناقصين)، ويُطابق
   الدور المختار مع `userTypeId` الصحيح ديناميكيًا، ويسجّل الدخول ويوجّه
   للمساحة الصحيحة بعد النجاح.

5. **`src/routes/teacher.register.tsx`** — نفس مبدأ signup.tsx لإنشاء
   حساب المعلّم الأساسي (اسم/إيميل/هاتف/جنس/كلمة مرور). حقول المادة/الخبرة/
   النبذة/وثيقة التوثيق **باقية بالنموذج بس ما بتنبعت للباك اند** لأنه ما
   إلها مكان هناك بعد (لا حقول ولا endpoint) — فيه ملاحظة واضحة بالواجهة
   نفسها لهيك.

6. **`src/integrations/backend/wallet.ts`** (ملف جديد) — تكامل كامل مع
   `WalletController`: المحفظة، سجل الحركات، طلب شحن (مع رفع صورة)، طلب
   سحب، ومسارات الأدمن (عرض/قبول/رفض الطلبات المعلّقة، تأكيد التحويل).

7. **`src/components/admin/wallet-requests-manager.tsx`** (ملف جديد) —
   شاشة أدمن حقيقية لمراجعة طلبات الشحن والسحب المعلّقة (بديل شاشة
   "المدفوعات" الوهمية القديمة). استُبدلت بها شاشة `admin.payments` مع
   الإبقاء على نفس `pageKey` ("admin_payments") حتى تضل الصلاحيات شغالة.

8. **`src/integrations/backend/parent.ts`** (ملف جديد) — تكامل مع
   `ParentController` (MyChildren/ChildAttendance/ChildExamResults) —
   **لسا مش موصول بأي شاشة UI** لأن شكل بيانات صفحة "تقرير الابن" الحالية
   (`parent.report.tsx`) وهمي بالكامل ولا يطابق شكل بيانات الباك اند
   الحقيقي (راجع الفجوة رقم 3 تحت). القرار محتاج توجيه منك.

9. **`src/integrations/backend/client.ts`** — إضافة `apiClient.postForm`
   (لطلبات multipart/form-data زي رفع صورة إشعار الشحن) و`apiClient.baseUrl`.

## 🐞 فجوات موثّقة — محتاجة قرار أو عمل بالباك اند (ما لمستها)

1. **CORS محلي**: الباك اند مسموح له `localhost:3000` بس، فرونت Vite
   شغال افتراضيًا عبـ`5173` — لازم تضاف بـ`Program.cs` (`AddCors`) أو
   يتحدد `server.port: 3000` بـ`vite.config.ts`. يحتاج إعادة نشر الباك اند.

2. **بوابة ولي الأمر غير قابلة للاستخدام فعليًا**:
   - `ParentService.LinkChildAsync` موجودة بالسيرفس لكن بدون endpoint
     بـ`ParentController` — لازم يُضاف action جديد.
   - "الطالب" (`Student`, `int Id`) كيان منفصل تمامًا عن `User` (Identity)،
     ومافي أي كود بالمشروع كله بينشئ صف `Student` — حتى لو أضفنا endpoint
     الربط، ما في طلاب موجودين أصلاً للربط معهم. يحتاج قرار: هل "الطالب"
     بالباك اند لازم يتوحّد مع `User`، أو يتضاف مسار ينشئ `Student` تلقائيًا
     عند تسجيل مستخدم بنوع "الطالب"؟

3. **تعارض بيانات "تقرير الابن"**: `parent.report.tsx` الحالية (وهمية)
   بتعرض دقائق دراسة يومية، نسبة إتقان لكل مادة، مواطن ضعف... والباك اند
   الحقيقي (`ParentController`) بيرجّع بس نسبة حضور، معدل امتحانات، وعدد
   إشعارات غير مقروءة. قرار منتج مطلوب: تبسيط الصفحة لتطابق الباك اند
   الحالي، أو توسيع الباك اند بنموذج بيانات "دقائق الدراسة/الإتقان".

4. **`GetPendingTopUpRequests` / `GetPendingWithdrawalRequests` بالباك
   اند ما فيها `.Include()`** على `Student`/`Instructor` — يعني الاستجابة
   فيها `studentId`/`instructorId` (نص) بس بدون اسم صاحب الطلب. شاشة
   الأدمن الجديدة بتعرض الـid مؤقتًا؛ لو ضفتوا `.Include()` بالسيرفس
   بيصير ممكن نعرض الاسم مباشرة بدون أي تغيير إضافي بالواجهة.

5. **مافي نظام تتبع (analytics) حقيقي بالمشروع** — `bi.ts` هو helper نصوص
   ثنائية اللغة فقط، مش تتبع أحداث. إذا محتاجين تتبع فعلي لعمليات الدخول/
   التسجيل/الأخطاء، هاد يحتاج قرار بأداة (مثلاً: نداء بسيط لـendpoint
   لوغ بالباك اند، أو أداة analytics خارجية) — ما فيه شي جاهز نربطه حاليًا.
